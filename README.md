# Лабораторная работа: растеризация отрезков алгоритмом Брезенхэма и заливка замкнутых областей

Программа на C, которая:
1. рисует отрезок по алгоритму Брезенхэма (корректно во всех 8 октантах);
2. строит замкнутый контур многоугольника из отрезков, построенных по алгоритму Брезенхема;
3. заливает внутренность контура по алгоритму flood fill.

Всё рисуется в символьной сетке 40 × 20 и печатается в консоль.

## Как пользоваться

После запуска появляется меню:

```
1 — отрезок
2 — многоугольник + заливка
0 — выход
Выбор:
```

### Сценарий 1 (отрезок)

Вводятся координаты начала и конца: `x0 y0` и `x1 y1`. Программа рисует отрезок по Брезенхэму и печатает сетку.

### Сценарий 2 (контур + заливка)

1. Вводится число вершин `n` (3..8).
2. Вводятся координаты вершин по одной: `x y`.
3. Строится контур (рёбра — отрезки Брезенхэма), печатается промежуточный результат.
4. Вводится затравка `x y` — точка внутри области.
5. Выполняется заливка, печатается результат и число закрашенных клеток.

## Обозначения в сетке

| Символ | Константа в коде | Значение |
|--------|------------------|----------|
| `.`    | `EMPTY`          | пустая клетка |
| `#`    | `WALL`           | граница / отрезок |
| `*`    | `FILL`           | закрашенная клетка |

Все три символа и размеры сетки (`WIDTH = 40`, `HEIGHT = 20`) вынесены в `grid.h`.

## Координаты и таблица

Сетка — 40 столбцов (`x = 0..39`) и 20 строк (`y = 0..19`).

- Ось X растёт вправо.
- Ось Y растёт вниз.

Пиксель `(x, y)` хранится в массиве как `grid[y][x]` (строка, потом столбец).

## Математика: алгоритм Брезенхэма

### Задача

Для отрезка из `(x0, y0)` в `(x1, y1)` выбрать для каждой целой координаты по ведущей оси такую координату по второй оси, чтобы пиксель был как можно ближе к настоящей прямой. Только целые числа, без делений и `float`.

### Переменные

```c
int dx = abs(x1 - x0);      // длина проекции на X, всегда >= 0
int dy = abs(y1 - y0);      // длина проекции на Y, всегда >= 0
int sx = sign(x1 - x0);     // направление шага по X: +1, -1 или 0
int sy = sign(y1 - y0);     // направление шага по Y: +1, -1 или 0
int err = dx - dy;          // функция решения
```

Внутри алгоритм считает как в первом октанте (все `dx`, `dy` положительны), а `sx`, `sy` разворачивают шаги в нужную сторону.

### Функция решения `err`

`err` кодирует накопленное отклонение от идеальной прямой:

- `err > 0` — «ниже» прямой, надо двигаться по X;
- `err < 0` — «выше» прямой, надо двигаться по Y;
- `err = 0` — точно на прямой (диагональ).

На каждом шаге:

```c
int e2 = 2 * err;
if (e2 > -dy) { err -= dy; x += sx; }   // шаг по X
if (e2 <  dx) { err += dx; y += sy; }   // шаг по Y
```

- `e2 > -dy` — «пора шагнуть по X», после шага штраф `err -= dy`.
- `e2 < dx` — «пора шагнуть по Y», после шага компенсация `err += dx`.
- Два условия независимы: на диагонали срабатывают оба, и за один шаг цикла меняются обе координаты.

### Параметры

| Параметр | Значение | Смысл |
|----------|----------|-------|
| `WIDTH`  | 40 | ширина сетки |
| `HEIGHT` | 20 | высота сетки |
| символ отрезка | `#` | `WALL` |

### Работа во всех 8 октантах

- `dx > 0, dy = 0` — горизонталь, шагаем только по X.
- `dx = 0, dy > 0` — вертикаль, шагаем только по Y.
- `dx = dy` — диагональ, шагаем по обеим осям.
- `dx > dy` — пологий наклон, чаще шаг по X.
- `dx < dy` — крутой наклон, чаще шаг по Y.
- Отрицательные `x1 - x0` / `y1 - y0` обрабатываются через `sx`, `sy`.

## Математика: flood fill

### Задача

Дана изначальная точка `(seedX, seedY)` внутри области. Нужно покрасить все клетки, которые:

1. связные с изначальной точкой (можно дойти по соседям);
2. имеют цвет `EMPTY` (не граница `WALL`, не уже покрашенные `FILL`).

### 4-связность

Соседи — только ортогональные:

```
      (x, y-1)
           |
(x-1,y) — (x,y) — (x+1,y)
           |
      (x, y+1)
```

Диагональные соседи `(x±1, y±1)` не рассматриваются.

Почему не 8-связность. Контур рисуется растровыми отрезками и представляет собой «лесенку» из клеток, которые могут соприкасаться только углами. 8-связная заливка может «протечь» через такой диагональный стык и закрасить внешнюю часть. 4-связная по диагонали не ходит — протечки невозможны.

### Защита от зацикливания

Если изначальная точка уже `FILL`, наивная заливка закрашивает её в тот же цвет, соседи снова проходят проверку «пустая», и цикл не останавливается.

### Параметры

| Параметр | Значение | Смысл |
|----------|----------|-------|
| связность | 4 | ортогональные соседи |
| `STACK_SIZE` | `WIDTH * HEIGHT * 4 + 1` | запас на повторные попадания клеток в стек |
| возврат | `int` | число закрашенных клеток |

## Проверка работы

Тестовые примеры (ручная сверка по печати сетки):

1. Отрезок `(0,0)–(5,2)` — первый октант. Ожидаемые `#`: `(0,0), (1,0), (2,1), (3,1), (4,2), (5,2)`.
2. Отрезок `(0,2)–(5,0)` — отрицательный наклон.
3. Отрезок `(3,0)–(3,5)` — вертикаль (`dx = 0`).
4. Отрезок `(0,3)–(5,3)` — горизонталь (`dy = 0`).
5. Отрезок `(5,0)–(0,5)` — диагональ, `dx < 0, dy > 0`.
6. Треугольник `(1,1), (8,1), (4,6)`, изначальная точка внутри — контур и заливка.
7. Квадрат с углами `(2,2)` и `(6,6)`, изначальная точка `(4,4)` — должно закраситься 9 клеток (внутренность 3 × 3 без границы).
8. Если задать изначальную точку снаружи контура — закрасится внешняя область (это корректно: flood fill закрашивает связную компоненту, а не «внутренность»).

## Ограничения

- Контур должен быть замкнутым и не самопересекающимся; иначе заливка «вытечет» наружу или поведение будет неочевидным.
- Изначальная точка должна быть строго внутри области (не на границе и не снаружи), если нужна заливка внутренности.
- Стек заливки фиксированного размера; при переполнении `push` молча игнорирует точку — в теории возможна неполная заливка.
- Сетка символьная, вывод — в консоль; в графические файлы (PGM/BMP/PNG) проект не пишет.
